---
> Local PC Branch 정리 
```shell
git branch -D feature-login_page  # 로컬 브랜치 삭제 명령어
git remote prune origin           # 원격 저장소(origin)에서 이미 삭제된 브랜치를 정리(삭제)하는 명령어
git branch -a                     # 전체 브랜치 조회 명령어 
```
