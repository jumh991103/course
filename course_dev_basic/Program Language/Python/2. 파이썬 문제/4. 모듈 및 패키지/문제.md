
## 주제 4: 사용자 정의 모듈 제작 및 패키지 구조 설계
다음과 같은 패키지 구조를 만들고 구현하세요:

```
mathtools/
├── __init__.py
├── basic/
│   ├── __init__.py
│   ├── arithmetic.py
│   └── geometry.py
└── advanced/
    ├── __init__.py
    └── statistics.py
```

각 모듈의 요구사항:
1. `arithmetic.py`: 기본 사칙연산 함수들 (add, subtract, multiply, divide)
2. `geometry.py`: 기하학 계산 함수들 (원의 넓이, 직사각형 넓이, 삼각형 넓이)
3. `statistics.py`: 통계 함수들 (평균, 중앙값, 표준편차)
4. 각 `__init__.py`에서 적절한 함수들을 import하여 사용하기 쉽게 설정
5. 메인 스크립트에서 `from mathtools.basic import arithmetic` 형태로 사용할 수 있도록 구성
