## 파이썬을 이용한 가상환경 구현 답변 
```shell
# 가상환경 생성 
# py -[파이썬 버전] -m venv [프로젝트명]
C:> py -3.13 -m venv myproject
# 가상환경 접속 
C:> .\myproject\Scripts\activate
# 패키지를 설치
(myproject) C:> pip install -r requirements.txt
```

---
## uv를 이용한 가상환경 구현 답변 
```shell
# 가상환경 생성 
# uv venv [프로젝트명] --python [파이썬 버전]
C:> uv venv myproject --python 3.13
# 가상환경 접속 
C:> .\myproject\Scripts\activate
# 패키지를 설치
(myproject) C:> uv pip install -r requirements.txt
```
