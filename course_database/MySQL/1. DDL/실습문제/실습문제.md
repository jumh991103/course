# MySQL DDL 기초 실습문제

---
## 문제 1. 수강생 테이블 만들기

다음 조건을 만족하는 `practice_students` 테이블을 생성하세요.

- `student_id`: 자동 증가 기본키
- `name`: 최대 50자, 필수
- `email`: 최대 120자, 필수, 중복 불가
- `birth_date`: 날짜
- `created_at`: 현재 시각을 기본값으로 저장
- 테이블과 모든 컬럼에 주석 작성

---
## 문제 2. 강의 테이블 만들기

다음 조건을 만족하는 `practice_courses` 테이블을 생성하세요.

- `course_id`: 자동 증가 기본키
- `title`: 최대 100자, 필수
- `price`: 금액, 0 이상만 허용
- `level`: `beginner`, `intermediate`, `advanced` 중 하나만 허용
- `is_active`: 참/거짓, 기본값은 `TRUE`
- 테이블과 모든 컬럼에 주석 작성

---
## 문제 3. 수강 신청 테이블 만들기

`practice_students`와 `practice_courses` 사이의 N:M 관계를 표현하는
`practice_enrollments` 테이블을 생성하세요.

- `enrollment_id`: 자동 증가 기본키
- `student_id`: `practice_students(student_id)`를 참조
- `course_id`: `practice_courses(course_id)`를 참조
- `enrolled_at`: 기본값은 오늘 날짜
- 한 학생은 같은 강의를 한 번만 신청할 수 있어야 함
- 테이블과 모든 컬럼에 주석 작성
