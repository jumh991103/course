# MySQL DML/DQL 기초 실습문제

CRUD 문제는 먼저 `00_setup_sample_data.sql`을 실행해 샘플 데이터를 준비한 뒤
풀이하세요. DQL 문제는 `DQL/mysqlsampledatabase.sql`로 복원한 `classicmodels`
데이터베이스에서 풀이하세요.

## 문제 1. CRUD

1. `students` 테이블에 본인 이름과 이메일을 가진 수강생을 추가하세요.
2. 추가한 수강생의 전화번호를 수정하세요.
3. 추가한 수강생을 이메일 조건으로 조회하세요.
4. 추가한 수강생을 삭제하세요.

## 문제 2. 조건 조회

1. MSRP가 150 이상인 상품을 가격이 높은 순서로 조회하세요.
2. 상품 라인이 `Motorcycles` 또는 `Classic Cars`인 상품을 조회하세요.
3. 구매 가격이 50에서 100 사이인 상품을 조회하세요.
4. 이름에 `Ford`가 포함된 상품을 조회하세요.

## 문제 3. 집계

1. 상품 라인별 상품 수를 조회하세요.
2. 상품 라인별 평균 구매 가격을 조회하세요.
3. 고객별 총 결제 금액을 조회하세요.
4. 주문 수가 5건 이상인 고객만 조회하세요.

## 문제 4. 조인

1. 주문번호, 고객명, 주문일, 주문 상태를 함께 조회하세요.
2. 고객명, 주문번호, 상품명, 주문 수량, 판매 가격을 조회하세요.
3. 상품 라인별 상품 수를 조회하세요.
4. 고객명, 담당 직원명, 담당 직원의 사무실 도시를 함께 조회하세요.

## 문제 5. 서브쿼리와 CTE

1. 평균 MSRP보다 비싼 상품을 조회하세요.
2. `Classic Cars` 상품을 주문한 고객을 서브쿼리로 조회하세요.
3. 결제 기록이 있는 고객을 `EXISTS`로 조회하세요.
4. CTE를 사용해 고객별 주문 수를 계산한 뒤, 5건 이상인 고객만 조회하세요.
