# [PostgreSQL 입문 강의자료](https://neon.com/postgresql/tutorial)
- PostgreSQL은 표준 SQL을 충실히 지원하면서도 확장 기능이 풍부한 오픈소스 관계형 데이터베이스(RDBMS)입니다.

```
[사용자] -> SQL 명령어 -> [PostgreSQL 서버] -> [데이터 저장/조회/분석]
```

---
## SQL이란?

> **SQL(Structured Query Language)** 은 데이터베이스에 명령을 내리는 **언어**입니다.

쉽게 말해, PostgreSQL에게 "이 데이터 찾아줘", "이 데이터 저장해줘", "이 데이터를 기준으로 분석해줘"라고 말하는 방법입니다.

```sql
-- 회원 테이블에서 모든 데이터 조회
SELECT * FROM 회원;

-- 이름이 '홍길동'인 회원만 조회
SELECT * FROM 회원 WHERE 이름 = '홍길동';
```

---
SQL 명령어는 크게 4가지 흐름으로 나눌 수 있습니다.

| 종류 | 명령어 | 하는 일 |
|------|--------|--------|
| 조회 | `SELECT` | 데이터 읽기 |
| 삽입 | `INSERT` | 데이터 추가 |
| 수정 | `UPDATE` | 데이터 변경 |
| 삭제 | `DELETE` | 데이터 제거 |

---
## PostgreSQL은 어디서 쓰이나요?

> PostgreSQL은 정확성과 안정성이 중요한 서비스에서 많이 사용됩니다.

| 서비스 | 활용 예시 |
|--------|---------|
| 쇼핑몰 | 상품, 주문, 결제 데이터 저장 |
| 금융 서비스 | 계좌, 거래, 정산 데이터 관리 |
| 지도 서비스 | 위치 정보와 공간 데이터 처리 |
| 데이터 분석 | 집계, 리포트, 대시보드 데이터 조회 |
| 백엔드 API | 회원, 게시글, 권한 정보 저장 |

---
## 왜 PostgreSQL을 배워야 하나요?

### 이유 1: SQL 기본기를 탄탄하게 익힐 수 있음

- 표준 SQL 문법을 충실히 지원
- `SELECT`, `JOIN`, `GROUP BY`, 서브쿼리, CTE를 체계적으로 연습 가능
- 다른 관계형 데이터베이스로 넘어갈 때도 기본기가 그대로 활용됨

### 이유 2: 실무에서 요구하는 기능이 풍부함

- 트랜잭션과 제약조건으로 데이터 무결성 관리
- `RETURNING`, `WITH`, Window Function 등 고급 쿼리 지원
- `JSONB`, 확장 기능, 다양한 인덱스로 복잡한 데이터도 다룰 수 있음

---
### 이유 3: 백엔드와 데이터 분석 모두에 잘 맞음

- Python, Java, Node.js 등 다양한 언어에서 연동 가능
- FastAPI, Django, Spring 같은 프레임워크와 함께 자주 사용
- pandas, SQLAlchemy, BI 도구와 연결해 분석 실습에도 활용 가능

### 이유 4: 안정성과 확장성이 좋음

- 여러 사용자가 동시에 읽고 쓰는 상황을 안정적으로 처리
- 작은 실습 프로젝트부터 실제 서비스 데이터베이스까지 확장 가능
- 오픈소스라 무료로 설치하고 학습할 수 있음

## PostgreSQL의 핵심 특징

| 특징 | 의미 |
|------|------|
| 관계형 데이터베이스 | 테이블, 행, 열로 데이터를 구조화 |
| 트랜잭션 | 여러 작업을 하나의 안전한 단위로 처리 |
| 제약조건 | 잘못된 데이터 입력을 데이터베이스 단계에서 방지 |
| 고급 쿼리 | CTE, Window Function, 서브쿼리 등 지원 |
| 확장 기능 | 필요에 따라 기능을 추가해 사용 가능 |
| JSONB | 관계형 DB 안에서 JSON 데이터도 효율적으로 저장 |

## PostgreSQL vs 다른 데이터베이스

| 비교 | PostgreSQL | MySQL | MongoDB | SQLite |
|------|------------|-------|---------|--------|
| 종류 | 관계형(RDB) | 관계형(RDB) | 비관계형(NoSQL) | 관계형(RDB) |
| 비용 | 무료 | 무료 | 무료 | 무료 |
| 난이도 | 보통 | 쉬움 | 보통 | 쉬움 |
| 사용처 | 복잡한 쿼리, 분석, 안정성 중심 서비스 | 웹 서비스 전반 | 빠른 개발, 유연한 구조 | 앱 내부, 소규모 |
| 특징 | 기능 풍부, 표준 SQL 강점 | 빠르고 단순한 운영 | 문서 기반 저장 | 파일 1개로 동작 |

---
## MySQL과 무엇이 다른가요?

| 구분 | MySQL | PostgreSQL |
|------|-------|------------|
| 강점 | 빠른 웹 서비스 개발, 단순한 운영 | 복잡한 쿼리, 데이터 무결성, 확장 기능 |
| SQL 학습 | 입문자가 접근하기 쉬움 | 표준 SQL과 고급 SQL을 함께 배우기 좋음 |
| 데이터 타입 | 기본 타입 중심 | 배열, JSONB, UUID 등 다양한 타입 지원 |
| 반환 문법 | 변경 후 별도 조회가 필요한 경우가 많음 | `INSERT`, `UPDATE`, `DELETE`에서 `RETURNING` 사용 가능 |

## 실습 환경 준비

> `PostgreSQL` 폴더에서 PostgreSQL 컨테이너를 실행합니다.

```shell
docker-compose up -d
```

---
> PostgreSQL 접속 정보는 `docker-compose.yml`에 맞춰 아래 값을 사용합니다.

| 항목 | 값 |
|---|---|
| Host | `localhost` |
| Port | `5432` |
| Database | `examples_db` |
| User | `admin` |
| Password | `admin123` |
