# PostgreSQL DML/DQL 기초 실습문제

CRUD 문제는 먼저 `00_setup_sample_data.sql`을 실행해 샘플 데이터를 준비한 뒤
풀이하세요. DQL 문제는 `DQL 기초/restore.sql`을 실행해 영화 대여점 샘플 테이블을
준비한 뒤 풀이하세요.

## 문제 1. CRUD

1. `students` 테이블에 본인 이름과 이메일을 가진 수강생을 추가하세요.
2. 추가한 수강생의 전화번호를 수정하세요.
3. 추가한 수강생을 이메일 조건으로 조회하세요.
4. 추가한 수강생을 삭제하세요.

## 문제 2. 조건 조회

1. 대여료가 4.99 이상인 영화를 대여료가 높은 순서로 조회하세요.
2. 등급이 `PG` 또는 `PG-13`인 영화를 조회하세요.
3. 길이가 60분에서 90분 사이인 영화를 조회하세요.
4. 이름이 `ann`으로 시작하는 고객을 대소문자 구분 없이 조회하세요.

## 문제 3. 집계

1. 등급별 영화 수를 조회하세요.
2. 등급별 평균 영화 길이를 조회하세요.
3. 고객별 총 결제 금액을 조회하세요.
4. 대여 횟수가 30건 이상인 고객만 조회하세요.

## 문제 4. 조인

1. 대여번호, 고객명, 영화 제목, 대여일을 함께 조회하세요.
2. 결제번호, 고객명, 직원명, 결제 금액, 결제일을 조회하세요.
3. 카테고리별 영화 수를 조회하세요.
4. 고객명, 주소, 도시, 국가를 함께 조회하세요.

## 문제 5. 서브쿼리와 CTE

1. 평균 대여료보다 비싼 영화를 조회하세요.
2. `Action` 카테고리에 속한 영화를 서브쿼리로 조회하세요.
3. 결제 기록이 있는 대여를 `EXISTS`로 조회하세요.
4. CTE를 사용해 고객별 대여 수를 계산한 뒤, 30건 이상인 고객만 조회하세요.
