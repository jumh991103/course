
## 문제 — 시맨틱 태그로 웹페이지 레이아웃 만들기
html, Bootstrap, js만 사용하세요.

### 요구사항
- html
  - HTML5 시맨틱 태그를 사용하여 웹페이지를 구성.
  - 다음 영역 포함:
    - `<header>`: 페이지 제목(H1)
    - `<nav>`: 메뉴 목록 3개 (홈, 소개, 연락처)
    - `<main>`: 기사(article) 1개와 사이드 정보(aside) 1개
    - `<footer>`: 저작권 정보
- Bootstrap 적용
  - 반응형 웹 구현
- js
  - 본문 내용을 바꾸는 버튼 만들기
    - 이벤트 실행 추가하기 
  - 본문 색상을 바꾸는 버튼 만들기
    - 이벤트 실행 추가하기
