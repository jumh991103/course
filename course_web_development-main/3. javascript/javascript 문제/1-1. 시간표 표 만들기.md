
## 문제 — 시간표 표 만들기
html, css, js만 사용하세요.

### 요구사항
- html
  - 수업 시간표를 표(table)로 작성.
  - 표 제목(caption) 포함.
  - 머리글(th)을 사용하고 scope 속성으로 열과 행 구분.
  - 시간, 월요일, 화요일, 수요일 4개의 열을 포함.
- css
  - Flex 레이아웃 적용 
  - 반응형 웹 구현(미디어 쿼리 적용)
- js
  - 셀 클릭 → 선택 표시
  - 셀 더블클릭 → 내용 수정
  - 행 추가 버튼
  - 열 추가 버튼
  - 선택된 셀 지우기 버튼
