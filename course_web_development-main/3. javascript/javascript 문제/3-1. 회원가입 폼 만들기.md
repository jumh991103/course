
## 문제 — 회원가입 폼 만들기
html, Tailwind, js만 사용하세요.

### 요구사항
- html
  - 아래 항목을 입력하는 폼을 만들 것:
    - 이름 (필수)
    - 이메일 (필수, `type="email"`)
    - 비밀번호 (필수, `type="password"`, 최소 8자)
    - 제출 버튼
  - `label` 태그와 `for` 속성을 사용하여 입력 필드와 연결.
  - `fieldset`과 `legend`로 폼 영역을 그룹화.
- Tailwind 적용
  - 반응형 웹 구현
- js
  - 이름, 이메일, 비밀번호에 대한 검증 이벤트 추가
